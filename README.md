# Global Airbnb Performance Dashboard | Power BI

## Overview
A guided learning project built by following a YouTube tutorial to practice Power BI dashboard development and data visualization using Airbnb data.

## Dashboard Pages
- **Overview:** Listing trends, market share by city, and average prices.
- **Ratings:** City-wise ratings and listing performance.
- **Reviews:** Review frequency, seasonality, and host identity verification.

## Tools Used
Power BI, DAX, and data visualization.

## Learning Outcomes
Practiced creating interactive dashboards, DAX measures, charts, filters, and data-driven insights.
